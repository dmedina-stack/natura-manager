# 🌿 Natura Gestión

**Natura Gestión** es una aplicación web móvil diseñada para facilitar la administración diaria de negocios de venta y reventa de cosméticos.

La aplicación centraliza clientes, ventas, cuentas corrientes, deudas, pagos, productos e inventario en una interfaz moderna, simple e intuitiva.

## ✨ Principales funcionalidades

- 👥 Gestión de clientes
- 💰 Registro y seguimiento de ventas
- 📒 Cuentas corrientes y deudas
- 💳 Registro de pagos parciales o completos
- 📦 Gestión de productos y stock
- ⚠️ Alertas de stock bajo
- 🛒 Gestión de pedidos
- 📊 Dashboard con indicadores del negocio
- 💵 Cálculo de costos y ganancias
- 🧾 Generación de presupuestos y comprobantes
- 📄 Estados de cuenta y reportes en PDF
- 💬 Integración con WhatsApp
- 📲 Mensajes predefinidos y personalizados para clientes
- 🔔 Sistema de notificaciones internas
- 🔎 Búsqueda y filtros
- ⚙️ Configuración personalizada del negocio
- 🌙 Modo claro y oscuro
- 🔐 Protección mediante PIN
- 💾 Exportación e importación de copias de seguridad

## 💬 WhatsApp

La aplicación permite preparar mensajes personalizados para clientes con deuda utilizando información dinámica como:

- Nombre del cliente
- Monto adeudado
- Saldo pendiente
- Fecha de vencimiento
- Nombre del negocio

El mensaje se prepara automáticamente y se abre en WhatsApp para que la usuaria pueda revisarlo y enviarlo.

## 📊 Gestión financiera

Natura Gestión permite visualizar rápidamente:

- Ventas del día
- Dinero cobrado
- Dinero pendiente de cobro
- Clientes con deuda
- Deudas vencidas
- Vencimientos del día
- Próximos vencimientos
- Ganancias de las ventas
- Gastos del negocio

## 📦 Inventario

El módulo de stock permite controlar productos, cantidades disponibles, precios y movimientos de inventario.

Las ventas actualizan automáticamente el stock y la aplicación puede advertir cuando un producto alcanza o queda por debajo del stock mínimo configurado.

## 📱 Diseño

La aplicación está pensada principalmente para utilizarse desde teléfonos móviles, con una interfaz moderna, rápida y sencilla.

Incluye:

- Diseño responsive
- Modo claro / oscuro
- Navegación intuitiva
- Tarjetas y paneles de información
- Acciones rápidas
- Interfaz optimizada para pantallas pequeñas

## 💾 Copias de seguridad

Actualmente la aplicación permite exportar los datos del negocio como archivo JSON y posteriormente restaurarlos desde una copia de seguridad.

- 🔄 Sincronización entre dispositivos

- ☁️ Copias de seguridad automáticas

## 🎯 Objetivo

El objetivo de Natura Gestión es ofrecer una herramienta sencilla y práctica para que revendedoras y pequeños emprendimientos puedan administrar clientes, ventas, cobros e inventario sin necesidad de utilizar sistemas administrativos complejos.
